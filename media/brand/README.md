# Browser Storage Inspector logo

Created with the built-in ImageGen tool. The mark combines a white storage stack and a light-blue inspection lens on a navy rounded tile. Pixels outside the tile are transparent.

- `logo-master.png`: original generated 1254 × 1254 source.
- `logo.png`: 512 × 512 preview and general-purpose logo.
- `../../packages/shell-chrome/icons/`: PNG exports at 16, 24, 32, 48, 64 and 128 px, using Lanczos resampling.
- `../../packages/shell-components/src/assets/logo.png`: 256 px panel asset, embedded in the UI bundle by Vite.
- `../chrome/icon-128.png` and `../300.png`: browser store icon exports.

The sidebar uses local SVG icons with a consistent 24-unit grid, 1.8-unit stroke and rounded caps. No external icon service or font is required.

## Generation prompt

```text
Use case: logo-brand.
Asset type: production browser-extension app icon, square raster master, for the existing Browser Storage Inspector developer tool.
Primary request: design one distinctive, extremely simple storage-inspection logo, optimized to remain legible at 16, 24 and 32 pixels.
Subject: a bold white database/storage stack of two clean rounded horizontal layers, integrated with one simple icy-blue magnifying-glass ring and short diagonal handle at the lower right. The stack and lens should read as one cohesive geometric symbol, with strong silhouettes and very few internal lines.
Style: precise flat vector-like graphic, crisp edges, professional developer tool identity. Match the app's existing deep navy (#243750), white and light blue UI. A single deep-navy rounded-square tile fills about 90 percent of the canvas; all corners rounded uniformly. The central white-and-light-blue symbol fills about 70 percent of the tile; generous balanced margins without excessive empty space.
Background: truly transparent pixels outside the rounded-square tile.
Composition: exactly one icon centered on a square canvas, straight-on, no surrounding presentation.
Constraints: no letters, no words, no typography, no gradients, no 3D, no shadows, no glow, no fine decoration, no mockup, no checkerboard texture, no watermark. Do not add any other objects. This is the actual reusable icon asset, not a logo presentation sheet.
```
